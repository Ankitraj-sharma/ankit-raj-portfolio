## ⚡ Key Highlights & Features

- **Editorial Layered Hero Section**:
  - Giant background stroke typography (`DEVELOPER`) with a layered cutout portrait creating high-end magazine depth.
  - Dynamic typewriter effect cycling through roles and core engineering domains.
  - Floating ambient stats cards (CGPA 7.91, 7+ Live Deployed Projects, 10+ Certifications).
- **Interactive Audio Micro-Interactions**:
  - Native Web Audio API sound synthesizer with futuristic clicks, hover tones, tab changes, and celebration chimes (with instant mute toggle).
- **Split Screen Bento Navigation Drawer**:
  - Sleek 9-dot bento icon triggering a fullscreen split navigation overlay with direct WhatsApp chat, email compose, and location metadata.
- **Production Projects Grid & Filters**:
  - Filterable tabs (`All`, `Full Stack`, `AI / ML`, `Frontend`) showcasing the Smart Online Examination System, TVB AI Agent, Intellmeet, Gujarat Tourism, and more with live links and GitHub repositories.
- **Interactive Recruiter CLI Terminal**:
  - Keyboard shortcut (`~` or \`) launches a built-in terminal simulator supporting commands: `help`, `bio`, `skills`, `projects`, `certs`, `contact`, `hire`, `clear`.
- **Verified Credentials & Awards**:
  - Tabular layout with one-click copyable verification IDs for Cisco Networking Academy, Infosys Springboard, Coursera (UMich), and Udemy.
- **Life Beyond Code Gallery**:
  - Showcase of personal passions, motorcycle night rides (KTM Duke 200), and late-night build grit with full interactive lightbox viewing.
- **100% Responsive & Dark/Light Mode**:
  - Seamless adaptation from 360px mobile viewports to 4K displays with custom cursor spotlight glow tracking.

## 🛠️ Built With

- **Frontend Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS + Custom CSS Modules + Glassmorphism
- **Icons**: Lucide React + Custom Brand SVGs (GitHub, LinkedIn, LeetCode, HackerRank)
- **Audio Synthesis**: Native Web Audio API (zero external sound assets needed)
- **Effects**: Canvas Confetti + Custom Cursor Tracking
- **Deployment**: GitHub Pages + GitHub Actions CI/CD

## 🚀 Local Development Setup

```bash
# Clone the repository
git clone https://github.com/Ankitraj-sharma/ankit-raj-portfolio.git

# Navigate to project folder
cd ankit-raj-portfolio

# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
